## ✨ Features

- **🌌 Real-Time 3D WebGL Canvas**: Built using Three.js with floating data particles, interactive grid planes, and responsive mouse parallax camera tracking.
- **🧑‍💻 Dual Avatar Modes**:
  - **Vector Cyber-Avatar**: Handcrafted SVG avatar with cyberpunk neon glow rings, cybernetic visor scanlines, and animated particle rings.
  - **3D Interactive Holographic Bust**: Low-poly Three.js wireframe model with 360-degree drag-to-rotate controls.
- **⚡ Interactive HUD Architecture**:
  - Filterable skill matrices across **Frontend & Languages**, **Backend & Databases**, and **DevOps & AI**.
  - Interactive project detail modal cards for **SensorGrid**, **Z Shop**, and **InsightDoc**.
  - **Ask AI Cyber Terminal (`Ctrl + ~`)**: CLI command terminal emulator for querying skills, experience, education, and contact channels.
  - **Flat / 3D Tilt View toggle**: Switch dynamically between perspective 3D HUD tilt and standard flat layout.
  - **Print / PDF Ready**: Dedicated print stylesheet formatted for clean PDF exports.
  - **One-click clipboard copying**: Fast copy buttons for email and phone with holographic toast notifications.

## 💻 Local Setup & Development

To run this project locally without any dependencies or build steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/razikuljoni/holographic-3d-resume.git
   cd holographic-3d-resume
   ```

2. **Open in Browser**:
   - Simply double-click `index.html` or serve with any static server:
   ```bash
   # Using Python 3
   python3 -m http.server 3000

   # Or using npx serve
   npx serve .
   ```
3. Open `http://localhost:3000` in your browser.
